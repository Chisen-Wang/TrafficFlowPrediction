# 精简版整理说明

## 保留范围

- TFP 主模型、TimeFilter 图注意力、UniCA 协变量适配器及既有 Ranger 优化器。
- PEMS04/07/08 与 NYC-Bike 的预处理、统一训练入口、NYC 上下文审计。
- 少样本加载、训练同步打乱、数据准备和指标等适用的单元测试。
- 可手动执行的完整数据核验及 GPU 集成检查。

## 排除范围

- `compare/` 基线模型、vendor/upstream 代码及其依赖。
- 历史批量队列、自动收尾脚本、定向调参脚本，以及仅测试这些脚本的测试。
- 旧 README 中实验进度、调参目标、个人运行记录和历史指标表。
- `.git/`、数据、训练权重、日志、缓存、编辑器配置、审计产物和大文件。

## 整理时的行为调整

| 项目 | 原工作目录 | 精简版 |
| --- | --- | --- |
| PEMS04 准备默认窗口 | 96 → 12 | 12 → 12，与其他 PEMS 一致 |
| PEMS04 训练默认窗口 | 12 → 3 | 12 → 12 |
| PEMS04 原始路径 | `dataset/` 中的旧命名 | `data/PEMS04/PEMS04.npz`、`PEMS04.csv` |
| PEMS04 默认训练数据目录 | 外部相邻项目 | 本仓库的 `data/pems04_<input>_<output>` |
| 自定义准备窗口的目录名 | PEMS04 固定旧后缀 | 使用实际输入、输出长度 |
| 直接训练输出时间戳 | 包含冒号 | 使用连字符 |
| PEMS 下载 | 旧脚本含未支持的 PEMS03 | 新工具只支持 04/07/08，记录 SHA-256 并检查数组及图 |

已有模型实现、优化器、评价指标及数据划分算法保留。
旧窗口仍可通过显式参数使用；数据准备与训练参数必须一致。
移除了测试中仅针对已删除实验调度器的部分，保留少样本数据加载回归测试。
原项目目录未因本次整理而修改。

## 发布状态

此整理包作为独立仓库发布，不包含原工作目录的 Git 历史。使用前请阅读 README 和验证记录。
`.gitignore` 排除了默认数据、权重、实验产物及常见凭据文件，不能替代之后新增文件的人工检查。
按维护者要求暂不指定项目许可证；来源状态见 `THIRD_PARTY_NOTICES.md`。
